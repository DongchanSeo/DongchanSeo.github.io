저장하는 정보와 이용

고양이 이름과 특징, 사용자가 선택한 사진, 만난 날짜·시각·장소·메모, 선택적으로 기록한 위치 좌표, 밥·간식·물 돌봄 내역, 고양이별 중성화·접종·병원·약·관찰·급식의 누적 일지, 사용자가 확인한 날짜·시각·장소·위치·근거·메모를 이 기기의 앱 저장공간에 보관합니다. 자유 입력에는 사용자가 직접 적은 다른 정보가 들어갈 수 있으니 사람의 민감한 정보는 적지 않도록 주의해 주세요.

사진은 친구 등록·편집 또는 기록 작성에서 사용자가 직접 선택합니다. 친구 등록·편집에서는 카메라 촬영도 선택할 수 있으며, 촬영을 선택할 때 카메라 권한을 요청합니다. 운영체제가 전달한 사진 사본을 원본으로 보관하고 얼굴 크롭이나 표시용 사본을 별도로 저장합니다. 기록에는 여러 사진을 연결할 수 있습니다. 이 과정은 기기 사진 보관함의 원본 사진을 수정하거나 삭제하지 않습니다. 백업에는 원본 사본과 파생 이미지가 포함될 수 있습니다.

친구 등록을 시작할 때 이미 위치 권한을 허용했고 초안에 위치가 없으면 현재 위치를 전경에서 한 번 제안할 수 있습니다. 통합 기록창을 열거나 초안을 이어 쓰는 것만으로 현재 GPS를 읽지 않습니다. 통합 기록에서는 사용자가 현재 위치 버튼을 직접 누를 때만 전경에서 현재 위치를 한 번 요청하며, 과거 시각의 기록에서는 지금 GPS 위치를 제안하지 않습니다. 위치 제안은 저장 전 확인하거나 지도 핀으로 보정합니다. 권한을 거부해도 수동 위치 선택이나 장소 메모로 기록할 수 있으며, 상시 위치 수집과 백그라운드 추적은 하지 않습니다.

기기 내 저장과 자동 전송

이 앱에는 로그인, Haru 서버 동기화, 광고, 분석 기능이 없습니다. 앱이 기록과 사진을 Haru 서버로 보내지 않습니다. 기록은 기기 안의 로컬 데이터베이스와 앱 전용 파일에 저장됩니다.

iOS 첫 화면, 지도 탭, 아이 상세와 만남·돌봄 위치 선택 화면은 Apple 지도를 사용해 이 기기에 저장된 만남 위치를 표시합니다. 지도 화면이 보일 때 Apple 지도 서비스의 지도 데이터를 불러오기 위한 네트워크 요청이 발생할 수 있고, 저장한 위치를 중심으로 지도를 보여주므로 요청을 통해 대략적인 화면 영역이 드러날 수 있습니다. 이 앱은 만남의 고양이 이름·사진·장소 메모·기억 메모·돌봄·건강 기록을 Haru 서버로 보내지 않으며, 현재 위치를 지도에 자동 표시하거나 위치 권한을 요청하지 않습니다. Android에서는 Google 지도 설정을 마치기 전까지 실제 지도 대신 관찰 지점 도식을 보여주고 좌표를 외부 지도 앱에 열지 않습니다. Apple 서비스의 처리는 Apple의 정책을 따릅니다. 지도 공급자가 받는 기술 정보와 정확한 처리 항목은 Apple 정책에서 확인해 주세요.

iOS 위치 선택에서 주소 검색 버튼을 누르면 입력한 주소·장소 검색어를 운영체제 지도 서비스에 전달해 위치 제안을 받습니다. 검색은 사용자가 직접 시작하고, 검색 제안은 핀이나 좌표로 확인하기 전까지 기록 위치로 저장하지 않습니다. Android 위치 선택은 좌표 수동 입력을 제공하며 주소 검색을 실행하지 않습니다.

앱은 데이터베이스와 사진 파일을 별도로 암호화하지 않습니다. 기기 잠금과 안전한 보관을 권장합니다. Android 자동 앱 백업은 꺼져 있습니다. iOS 기기 백업은 기기·계정 설정에 따라 앱 데이터를 포함할 수 있으며, Haru는 운영체제 백업을 받거나 관리하지 않습니다.

Apple 서비스의 정보는 Apple 지도와 개인정보 및 Apple 개인정보 보호 정책에서 확인해 주세요.

백업과 공유

사용자가 백업 내보내기를 선택하면 고양이·만남·돌봄 기록, 사진, 위치 좌표가 포함될 수 있는 일반 JSON 파일을 만듭니다. 이 파일은 앱에서 암호화하지 않습니다. 운영체제 공유 화면에서 사용자가 선택한 저장 위치나 앱으로 전송되므로, 공유할 대상과 저장 위치를 직접 확인하고 안전하게 보관해 주세요. 선택한 외부 서비스의 처리 방식은 해당 서비스의 정책을 따릅니다.

우리동네 친구들 포스터는 사용자가 직접 정한 동네 제목과 선택한 친구의 동그란 얼굴 사진, 이름만 담습니다. 위치 좌표와 돌봄·건강 메모는 포스터에 포함되지 않습니다. 포스터 공유도 사용자가 운영체제 공유 화면에서 대상을 선택할 때만 이뤄집니다.

보관 기간과 삭제

Haru는 서버에 사용자 기록이나 사진 사본을 보관하지 않습니다. 기기 안의 앱 데이터는 사용자가 앱을 제거할 때까지 남습니다. 만남 기록을 복구함으로 옮기거나 이전 저장 상태가 남아 있을 수 있으며, 현재 앱은 고양이 프로필·사진·건강 기록을 영구 삭제하는 기능을 제공하지 않습니다. 기기 안의 모든 앱 데이터를 없애려면 앱을 기기에서 제거해 주세요. 사용자가 내보낸 백업 파일은 선택한 저장 위치나 공유 대상 앱에서 별도로 삭제해야 합니다.

사진 또는 위치 권한은 기기 설정에서 언제든 바꿀 수 있습니다. 권한을 끄더라도 이미 앱 안에 저장된 기록은 자동 삭제되지 않습니다.
