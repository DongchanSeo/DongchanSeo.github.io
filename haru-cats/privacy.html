마지막 업데이트: 2026-10-05

고양이 기록은 이 기기에 보관됩니다. 사진과 위치는 선택 기능이며, 백업과 공유는 사용자가 직접 시작합니다.

앱 지원개인정보 문의

적용 범위와 문의

이 방침은 Haru 우리동네 길냥이 iOS·Android 앱에 적용됩니다. 개인정보 관련 문의는 eternalamour@naver.com으로 보내 주세요.

저장하는 정보와 이용

고양이 이름과 특징, 사용자가 선택한 사진, 만난 날짜·시각·장소·메모, 선택적으로 기록한 위치 좌표, 밥·간식·물 돌봄 내역, 고양이의 중성화·접종·건강 메모를 이 기기의 앱 저장공간에 보관합니다. 자유 입력에는 사용자가 직접 적은 다른 정보가 들어갈 수 있으니 사람의 민감한 정보는 적지 않도록 주의해 주세요.

프로필 사진은 사용자가 기기 사진 선택 화면에서 고른 뒤 앱 전용 저장공간에 JPEG 사본으로 보관합니다. 이 과정은 앱 밖의 원본 사진을 수정하거나 삭제하지 않습니다.

위치는 사용자가 만남 기록에서 현재 위치 버튼을 눌렀을 때만 전경에서 요청합니다. 위치 권한 없이 장소 메모로 기록할 수 있으며 백그라운드 위치 추적은 하지 않습니다. 현재 동네 지도 화면은 관찰 지점을 보여주는 도식이며 외부 지도 제공자나 실제 도로 지도를 사용하지 않습니다.

기기 내 저장과 자동 전송

이 앱에는 로그인, Haru 서버 동기화, 광고, 분석 기능이 없습니다. 앱이 기록과 사진을 Haru 서버로 보내지 않습니다. 기록은 기기 안의 로컬 데이터베이스와 앱 전용 파일에 저장됩니다.

앱은 데이터베이스와 사진 파일을 별도로 암호화하지 않습니다. 기기 잠금과 안전한 보관을 권장합니다. Android 자동 앱 백업은 꺼져 있습니다. iOS 기기 백업은 기기·계정 설정에 따라 앱 데이터를 포함할 수 있으며, Haru는 운영체제 백업을 받거나 관리하지 않습니다.

백업과 공유

사용자가 백업 내보내기를 선택하면 고양이·만남·돌봄 기록, 사진, 위치 좌표가 포함될 수 있는 일반 JSON 파일을 만듭니다. 이 파일은 앱에서 암호화하지 않습니다. 운영체제 공유 화면에서 사용자가 선택한 저장 위치나 앱으로 전송되므로, 공유할 대상과 저장 위치를 직접 확인하고 안전하게 보관해 주세요. 선택한 외부 서비스의 처리 방식은 해당 서비스의 정책을 따릅니다.

우리동네 친구들 포스터는 사용자가 선택한 고양이의 사진과 이름만 담습니다. 위치 좌표와 돌봄·건강 메모는 포스터에 포함되지 않습니다. 포스터 공유도 사용자가 운영체제 공유 화면에서 대상을 선택할 때만 이뤄집니다.

보관 기간과 삭제

Haru는 서버에 사용자 기록이나 사진 사본을 보관하지 않습니다. 기기 안의 앱 데이터는 사용자가 앱을 제거할 때까지 남습니다. 만남 기록을 복구함으로 옮기거나 이전 저장 상태가 남아 있을 수 있으며, 현재 앱은 고양이 프로필·사진·건강 기록을 영구 삭제하는 기능을 제공하지 않습니다. 기기 안의 모든 앱 데이터를 없애려면 앱을 기기에서 제거해 주세요. 사용자가 내보낸 백업 파일은 선택한 저장 위치나 공유 대상 앱에서 별도로 삭제해야 합니다.

사진 또는 위치 권한은 기기 설정에서 언제든 바꿀 수 있습니다. 권한을 끄더라도 이미 앱 안에 저장된 기록은 자동 삭제되지 않습니다.

변경 안내

앱의 데이터 처리 방식이 바뀌면 앱과 공개된 개인정보 처리방침을 함께 업데이트하겠습니다.
