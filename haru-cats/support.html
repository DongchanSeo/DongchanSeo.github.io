Haru 우리동네 길냥이 앱 지원

앱은 고양이의 이름·사진·만남·돌봄 기록을 이 기기에 보관합니다. 계정이나 서버 동기화는 사용하지 않습니다.

개인정보 처리방침이메일로 문의

자주 묻는 내용

  • 위치 권한을 허용하지 않아도 되나요? 네. 현재 위치 기록은 선택 기능입니다. 권한 없이 장소 메모로 기록할 수 있습니다. 위치 권한은 사용자가 기록 화면에서 현재 위치를 누를 때 요청하며 백그라운드 추적은 하지 않습니다.
  • 사진 접근을 허용해야 하나요? 사진은 사용자가 사진 선택 화면에서 직접 고른 뒤에만 앱에 사본으로 보관됩니다. 카메라와 마이크는 사용하지 않습니다.
  • 백업 파일을 공유해도 안전한가요? 백업은 암호화되지 않은 JSON 파일이며 사진, 돌봄 기록, 위치 좌표가 포함될 수 있습니다. 선택한 저장 위치나 공유 앱을 확인하고, 다른 사람에게 보내기 전에 내용을 살펴 주세요.
  • 포스터에 위치나 건강 기록이 들어가나요? 아니요. 포스터에는 선택한 친구의 얼굴 사진과 이름만 담깁니다.
  • 지도에서 실제 도로나 영역을 볼 수 있나요? 아니요. 현재 화면은 사용자가 기록한 관찰 지점을 그린 도식이며 실제 도로 지도나 위치 기반 경로 안내가 아닙니다.
  • 기록을 완전히 삭제하려면 어떻게 하나요? 현재 앱은 고양이 프로필·사진·건강 기록을 영구 삭제하는 기능을 제공하지 않습니다. 기기 안의 모든 앱 데이터를 없애려면 앱을 제거해 주세요. 내보낸 백업 파일은 선택한 저장 위치에서 별도로 삭제해야 합니다.

개인정보 보호

지원팀은 앱 안의 로컬 기록을 볼 수 없습니다. 문의 시 앱 버전, 기기 모델, 운영체제 버전, 재현 순서를 알려 주시면 도움이 됩니다. 고양이 사진, 정확한 위치, 건강 메모, 전체 백업 파일은 이메일에 첨부하지 마세요.

개인정보 처리 방식은 개인정보 처리방침에서 확인할 수 있습니다.
