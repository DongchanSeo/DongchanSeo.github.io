Haru 우리동네 길냥이 앱 지원

앱은 고양이의 이름·사진·만남·돌봄 기록을 이 기기에 보관합니다. 계정이나 서버 동기화는 사용하지 않습니다.

위치 권한을 허용하지 않아도 되나요?

네. 위치 권한 없이 만남을 저장할 수 있습니다. iOS에서는 지도에서 선택한 점을 저장하고, 아무 점도 선택하지 않으면 위치를 기록하지 않습니다. 밥·약·관찰·병원·접종·중성화 입력에는 위치가 없으며 과거 기록의 위치는 보존합니다.

사진 접근을 허용해야 하나요?

친구 등록·편집과 기록 작성에서 사용자가 운영체제 사진 선택 화면으로 직접 고른 사진만 앱에 보관합니다. 친구 등록·편집에서는 카메라 촬영을 선택할 수 있고 촬영 선택 시 카메라 권한을 요청합니다. 원본 사본과 얼굴 크롭·표시용 사본을 별도로 보존하며 기기 사진 보관함의 원본을 수정하거나 삭제하지 않습니다. 마이크 녹음 기능은 없습니다.

백업 파일을 공유해도 안전한가요?

백업은 암호화되지 않은 JSON 파일이며 사진, 돌봄 기록, 위치 좌표가 포함될 수 있습니다. 선택한 저장 위치나 공유 앱을 확인하고, 다른 사람에게 보내기 전에 내용을 살펴 주세요.

포스터에 위치나 건강 기록이 들어가나요?

포스터에는 직접 정한 동네 제목, 선택한 친구의 얼굴 사진과 이름만 담깁니다. 정확한 위치 좌표와 돌봄·건강 메모는 포함되지 않습니다.

지도에서 실제 도로나 영역을 볼 수 있나요?

iOS는 저장된 만남과 과거 관찰 위치를 Apple 지도에 표시합니다. 한 곳은 점, 두 곳은 참고선, 세 곳 이상은 참고 범위이며 실제 이동 경로나 확정 서식지가 아닙니다. 아이별 얼굴·이름·색으로 선택할 수 있습니다. Android는 실제 지도 설정 전 관찰 지점 도식을 표시합니다.

기록을 완전히 삭제하려면 어떻게 하나요?

현재 앱은 고양이 프로필·사진·건강 기록을 영구 삭제하는 기능을 제공하지 않습니다. 기기 안의 모든 앱 데이터를 없애려면 앱을 제거해 주세요. 내보낸 백업 파일은 선택한 저장 위치에서 별도로 삭제해야 합니다.

돌봄 이력은 어떻게 남기나요?

행동과 친구를 고르면 추가 입력 없이 저장할 수 있습니다. 시간·위치·지도·사진은 만남에서만 선택합니다. 다른 행동에는 해당 내용·메모만 선택적으로 적고, 의료 상태를 고르지 않으면 모름으로 남깁니다. 여러 친구의 의료 상태와 내용은 서로 전파하지 않습니다. 근거 입력과 확인 단계는 없으며 과거 기록의 근거·날짜·위치·사진은 유지됩니다.
