기기 안에 보관하는 기록

마이크 권한은 사용자가 앱 화면에서 시작하는 최대 10분 녹음에 사용합니다. 녹음, 제목, 수동 메모, 전사, 요약, 생성 시각, 길이와 처리 상태는 앱 전용 기기 저장소에 보관합니다. 각 기록에는 선택한 한국어 또는 영어를 저장합니다. 마이크 권한을 거부해도 수동 메모를 사용할 수 있습니다. 자주 쓰는 이메일 수신 주소 하나는 기기 내 설정에 저장하며 별도로 지울 수 있습니다.

18세 이상 이용 확인

이 앱은 18세 이상 이용자를 대상으로 합니다. 앱 진입 시 이용자가 18세 이상이라고 확인한 여부만 기기에 저장하며 생년월일, 신분 정보나 Google 계정 정보를 요청하지 않습니다. 이 확인은 신원이나 나이 인증 서비스가 아닙니다. 확인을 초기화하면 다음 진입에서 다시 확인하며 기존 녹음과 메모는 삭제되지 않습니다. Google Play의 계정 기반 미성년자 접근 제한은 Google Play에서 처리합니다.

온디바이스 AI와 Google SDK 정보

지원 기기에서는 공식 ML Kit 기능으로 한국어·영어 전사와 요약을 기기 안에서 처리합니다. ML Kit의 공식 안내에 따르면 처리 입력과 결과는 Google 서버로 전송되지 않습니다. 앱은 녹음이나 텍스트를 외부 LLM 또는 개발자 서버에서 처리하는 대체 기능을 제공하지 않습니다. 모델과 시스템 구성 준비에는 Android/Google 시스템 서비스의 네트워크 사용이 필요할 수 있습니다.

SDK 진단·사용 정보

Google의 공식 ML Kit 공개 자료에는 기기·앱 정보, 사용자·기기 또는 기타 식별자와 설치별 식별자, 처리 지연·설정·입출력 크기·기능 이용 이벤트·오류 코드·설정 언어의 수집이 안내되어 있습니다. Google은 SDK 성능 확인과 진단, 유지·개선, 악용 탐지에 통계를 사용합니다. SDK 통계의 Google 전송은 HTTPS를 사용하며 녹음·메모의 온디바이스 처리와 구분됩니다. Google의 처리에는 아래 제공자 안내와 개인정보처리방침이 적용됩니다.

메일 앱으로 보내는 초안

메일 준비는 별도 안내와 동의 후 사용자가 선택한 외부 메일 앱에 수신 주소, 제목, 요약 또는 수동 메모를 넘깁니다. 요약과 수동 메모가 없으면 저장된 내용이 없다는 문구를 사용하며 전사를 자동 포함하지 않습니다. 전사와 오디오는 선택 사항입니다. 오디오를 선택하면 선택한 메일 앱에 첨부를 읽을 권한을 부여합니다. 앱은 메일을 자동 발송하지 않습니다. 최종 수신자·내용·첨부를 검토한 뒤 사용자가 직접 발송합니다. 외부 메일 앱은 발송 전에도 초안을 동기화할 수 있으며 그 앱과 서비스의 정책이 적용됩니다.

보관과 삭제

로컬 기록은 사용자가 보관하는 동안 기기에 남습니다. 목록이나 상세 화면에서 삭제를 확인하면 해당 기록의 녹음, 제목, 수동 메모, 전사와 요약을 삭제합니다. 진행 중인 작업을 끝내거나 취소한 뒤 삭제할 수 있습니다. 삭제 실패는 안내하며 다음 실행에서 사용자가 이미 확인한 삭제만 다시 마무리합니다. 오래된 처리 결과가 삭제된 내용을 되살리지 않도록 내용 없는 식별 기록은 앱 데이터 삭제 또는 앱 제거 전까지 유지합니다. 메모 삭제는 별도로 저장한 수신 주소와 외부 메일 앱의 사본을 삭제하지 않습니다. 앱 데이터 삭제 또는 앱 제거로 로컬 기록을 삭제할 수 있습니다. 앱 설정에서 자동 백업과 기기 이전을 제외하지만 제조사·운영체제의 동작은 다를 수 있습니다. 로컬 삭제는 Google의 SDK 통계나 외부 서비스 사본의 삭제를 보장하지 않습니다.
