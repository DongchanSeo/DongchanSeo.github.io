내 표를 나만의 공부 자료로

적용 대상: 새 UI 개편 버전 1.0.0(2) 예정. 아래 기능 설명은 이 개편 버전을 기준으로 하며, 기존 TestFlight 1.0.0(1)과 다를 수 있습니다.

최초 게시일: 2026년 10월 27일 (UTC)

Google Sheets에서 자료를 읽고, 실제 표의 열을 눌러 문제와 정답을 고르는 iPhone 학습 앱입니다.

시작하기

  1. 읽기 권한이 있는 Google Sheets 링크를 입력하고 사용할 자료를 고릅니다. 앱은 원본을 수정하지 않습니다.
  2. 표에서 문제와 정답에 사용할 열을 선택합니다. 필요한 경우 여러 열, 힌트·보기·설명을 함께 연결합니다.
  3. 실제 문제 미리보기와 공부할 범위를 확인한 뒤 자료를 저장합니다.
  4. 카드·맞춤 학습·직접 쓰기·시험·짝맞추기·복습 중 자료에 맞는 방식을 고릅니다.

자주 묻는 내용

인터넷 없이 공부할 수 있나요?
기기에 성공적으로 저장한 자료는 오프라인으로 공부할 수 있습니다. 새 자료나 원본 변경 내용은 연결 후 다시 불러와야 합니다.

시트가 열리지 않아요.
주소, 탭 및 읽기 권한을 확인해 주세요. 조직 제한이나 원본 소유자의 설정으로 읽을 수 없는 문서는 앱이 권한을 변경하지 않습니다. 민감정보가 있는 문서를 연결을 위해 공개하지 마세요.

진도와 수정 내용은 어디에 있나요?
기기의 앱 저장소에 보관합니다. 앱 삭제 전에 필요한 자료를 백업하고, 내보낸 파일과 OS 백업은 별도로 관리해 주세요.

질병 자료는 의료 상담에 사용할 수 있나요?
아닙니다. 앱은 사용자가 제공한 내용을 외우는 도구이며 진단·의료 상담이나 자료의 의학적 정확성 검증을 제공하지 않습니다.
