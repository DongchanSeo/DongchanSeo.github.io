하루 스터디는 사용자가 선택한 Google Sheets 자료와 기기에 저장한 자료로 공부하는 앱입니다. 이 방침은 앱의 자료 처리와 사용자가 직접 선택하는 외부 연결을 설명합니다.

1. 개발자가 수집하는 정보

앱은 개발자 서버, 회원가입, 외부 AI, 광고 또는 분석 SDK를 사용하지 않습니다. 개발자가 학습자료, 입력한 답안, 진도, 별표, 어려운 항목, 검색 내용이나 시트 주소를 수집하는 기능은 없습니다.

앱은 사용자의 Google 계정 로그인 쿠키나 Google API 비밀키를 요구하지 않습니다.

2. Google Sheets를 읽을 때

사용자가 연결하거나 다시 불러오기를 선택하면, 앱은 입력한 Google Sheets 문서의 탭과 셀 표시값을 Google에 직접 요청합니다. 이 과정에서 문서 주소와 요청 정보 및 네트워크 주소가 Google에 전달될 수 있습니다. 이는 개발자 서버로 자료를 전송하는 기능이 아닙니다.

읽기 가능한 문서만 지원하며, 앱이 원본 문서나 공유 권한을 변경하지 않습니다. 링크 공개 여부는 원본 소유자의 설정에 따릅니다. 민감정보를 앱 연결을 위해 공개하지 마세요. 원본 문서 열기를 선택하면 외부 Google 앱이나 브라우저로 이동할 수 있습니다.

3. 기기 안에 보관하는 내용

내려받은 학습자료, 사용자가 기기에서 수정한 내용, 자료 구성, 학습 답안과 진도, 시험·복습 기록, 중단한 작업 초안, 선택해 추가한 이미지와 설정은 앱 저장소에 보관됩니다. 받아 둔 자료의 학습에는 네트워크 연결이 필요하지 않습니다. 원본의 새 내용을 읽으려면 다시 연결해야 합니다.

기존 버전에서 보관된 기록이나 미디어 파일은 관련 기능이 더 이상 제공되지 않더라도 자동으로 삭제하지 않습니다. 앱은 새로운 음성 읽기나 녹음 기능을 제공하지 않습니다.

기기와 운영체제의 백업 설정에 따라 앱 데이터가 OS 백업에 포함될 수 있습니다. 앱 삭제·재설치 후 복구는 사용자가 가진 백업에 달려 있으며 자동 복구를 보장하지 않습니다.

4. 사용자가 선택하는 파일과 공유

사진 선택기나 파일 선택기를 사용하면 사용자가 고른 파일을 읽어 기기에 보관합니다. 클라우드 저장소에 있는 파일을 선택한 경우 해당 저장소나 운영체제가 다운로드할 수 있으며 그 서비스의 정책이 적용됩니다.

사용자가 PDF, 자료 또는 백업을 내보내고 공유 대상을 선택하면 그 파일이 선택한 앱·저장소·사람에게 전달될 수 있습니다. 진도 포함 여부와 내보내기 내용을 확인해 주세요. 내보낸 뒤의 파일은 수신 대상과 사용자가 관리합니다.

5. 보관과 삭제

앱의 보관함으로 이동하는 동작은 영구 삭제가 아닙니다. 연결을 보관하거나 원본에서 셀을 삭제해도 이전 학습·시험 스냅샷, 로컬 편집과 별도 백업에 내용이 남을 수 있습니다. 앱 삭제 시 기기의 앱 데이터가 삭제될 수 있으나 OS 백업과 사용자가 내보낸 파일까지 자동 삭제되지는 않습니다. 별도 백업은 해당 저장 위치에서 관리해 주세요.

6. 알림

사용자가 허용한 복습 알림은 기기 안에서 예약하는 로컬 알림입니다. 알림을 위해 학습 기록을 개발자 서버로 전송하지 않습니다. 권한은 기기 설정에서 변경할 수 있습니다.

7. 외부 지원과 방침 변경

지원 게시판을 열면 GitHub의 정책이 적용됩니다. 앱의 처리 방식이 바뀌면 이 페이지를 갱신합니다.
