지원

회의 녹음을 남긴 뒤, 준비 상태를 확인하고 내용을 다시 살펴보세요.

지원되는 기기와 언어에서 저장한 녹음을 기기 내에서 전사·요약할 수 있습니다. 새 녹음 또는 오디오 가져오기로 시작하고, 보관함에서 저장한 메모를 열어 원본을 들어 보세요.

설정은 전사와 요약 상태를 따로 표시합니다. 전사가 준비되지 않아도 녹음 저장과 재생은 가능합니다. 필요한 리소스를 준비한 뒤 처리를 재시도하고, 전사·요약 초안은 원본과 비교해 확인하세요.

안내 업데이트: 2026-10-05 · 버전 0.1.0 (9) · iOS·iPadOS·watchOS · 한국어·영어 화면

기기·언어·모델 상태

iPhone과 iPad는 iOS/iPadOS 26 이상이 필요합니다. 선택 사항인 Watch 기능은 watchOS 26과 페어링된 iPhone이 필요합니다. 앱 화면은 한국어와 영어를 지원합니다. 노트 처리 언어와 화면 언어는 별개이며, 설정에서 한국어·영어(미국)·일본어를 선택할 수 있지만 실제 지원 여부는 기기와 모델 상태에 따라 달라집니다.

전사는 선택한 언어의 Apple 기기 내 음성 리소스가 필요합니다. 요약과 제목 초안은 호환 기기, 켜진 Apple Intelligence, 설치되어 사용 가능한 Apple 기기 내 모델, 지원 로케일이 필요합니다. 전사 준비 상태와 요약 준비 상태는 각각 표시됩니다.

처음 사용할 때 음성 리소스 준비를 시도할 수 있습니다. Apple 리소스를 내려받으려면 인터넷이 필요할 수 있으며, Apple Intelligence 준비는 시스템 설정을 따릅니다. 설정에서 선택 언어와 현재 상태를 확인하고 상태를 새로고침하거나 제공되는 음성 준비 재시도를 이용하세요. 앱으로 돌아오면 상태를 새로 확인합니다. 요약 모델 다운로드 진행률은 제공하지 않습니다. 처리할 수 없어도 사용 가능한 원본 음성은 보존하며 서버 AI로 대신 처리하지 않습니다.

녹음 → 저장 → 모델 상태 → 초안 검토

새 녹음을 선택해 녹음을 시작하고 필요하면 일시정지·계속 녹음을 사용하세요. 녹음 끝내고 저장을 누르면 먼저 저장한 뒤 필요한 모델이 준비되면 전사·요약을 시도합니다. 저장 후 녹음 화면이 닫히면 목록에서 노트와 처리 상태를 확인하세요.

처리가 대기하거나 실패하면 설정에서 선택한 언어의 전사와 요약 상태를 따로 확인하세요. 마이크·음성 인식 권한, 남은 저장 공간, 표시된 오류도 확인하세요. 이전 기기 내 음성 경로는 60초 이하 녹음으로 제한됩니다. 리소스가 준비된 뒤 처리를 재시도하세요. 녹음과 재생에는 AI 요약이 필요하지 않습니다.

저장된 노트에서 원본 음성을 듣고 전사문과 요약 초안을 비교하세요. AI 초안에는 오류나 누락이 있을 수 있고 긴 전사문을 압축할 때 세부 내용이 빠질 수 있습니다. 내보내기나 전송 전에 최신 여부와 초안 경고를 확인하세요. 이전 요약은 기록에 남으며 재전사는 현재 전사문을 교체합니다.

저장이 실패하면 재시도·복구 상태를 확인하고 저장에 성공할 때까지 원본을 보존하세요. 중단된 녹음은 복구를 위해 남을 수 있지만 손상되거나 끝나지 않은 음성을 항상 복구할 수 있는 것은 아닙니다.

내보내기·메일·이전 노트

원본 오디오 내보내기와 메일 오디오 첨부는 M4A 파일만 지원합니다. 다른 형식으로 가져온 오디오는 M4A로 변환하지 않습니다. 원본 M4A 음성, 저장된 전사 시간 정보를 바탕으로 한 SRT/VTT 자막, 검토해 선택한 Markdown/텍스트를 내보낼 수 있습니다. 문서 내보내기에 원본 그림·이미지·음성이 포함되지는 않습니다. 이전 글·필기·이미지는 읽기와 내보내기만 가능하며 새 글이나 필기를 만들거나 편집하지 않습니다.

메일로 보내기는 편집 가능한 시스템 Mail 초안 또는 공유 대안을 엽니다. 받는 사람·제목·본문·선택 내용을 검토하세요. 전체 전사 TXT와 원본 M4A 첨부는 기본으로 꺼져 있고 첨부 합계는 20 MiB로 제한되며 메일 서비스의 한도가 더 작을 수 있습니다. 최종 전송은 선택한 앱에서 직접 결정합니다. 시스템 전송·대기열 또는 공유 결과가 수신 완료를 증명하지는 않습니다.

선택 사항인 iCloud와 Watch

새로 설치하면 iCloud Drive 동기화는 꺼져 있습니다. 켜면 저장된 노트 파일이 본인의 Apple 계정으로 전송됩니다. iCloud Drive 사용 가능 여부를 확인하고 지금 동기화 또는 새로고침을 이용하세요. 다운로드 뒤에는 다시 새로고침이 필요할 수 있습니다. 충돌은 둘 다 보관·로컬 버전·iCloud 버전 중 직접 선택해 해결하세요. 동기화를 꺼도 기존 클라우드 버전은 남습니다. OS 기기 백업은 별도의 시스템 설정을 따릅니다.

Watch에서 녹음하는 동안 앱을 열어 두세요. 녹음을 멈추면 페어링된 iPhone으로 보낼 대기열에 들어가며 전송은 비동기입니다. 전사와 요약은 iPhone에서 처리하고 결과를 Watch로 돌려보낼 수 있습니다. 두 앱 상태를 확인하고 필요하면 전송 다시 확인을 이용하세요. 고정 전송 시간이나 Watch 3시간 녹음은 입증되거나 보장되지 않았습니다.

최근 삭제·복원·독립된 사본

노트를 삭제하면 이 기기의 노트가 최근 삭제로 이동합니다. 설정의 최근 삭제에서 복원하거나 명시적으로 영구 삭제할 수 있습니다. 자동 만료는 없습니다. 복원하면 원래 노트 식별자와 자산이 유지됩니다.

영구 삭제는 해당 로컬 노트 자산, 관련 임시 초안·수신 기록, 검증된 앱 소유 노트별 내보내기 캐시를 제거합니다. 안전한 정리가 끝나지 않으면 삭제된 노트를 복원하거나 다시 시도할 수 있습니다. iCloud 버전·Watch 원본·다른 기기의 노트·이미 내보내거나 공유하거나 메일로 보낸 파일·백업은 함께 삭제되지 않습니다. 각 위치에서 사본을 별도로 관리하세요. 앱 삭제는 로컬 앱 데이터를 제거하지만 앱 정리하기는 데이터를 남길 수 있고 백업 복원으로 데이터가 돌아올 수 있습니다.

영구 삭제 뒤에도 이전 iCloud·Watch 전송으로 노트가 다시 생기는 것을 막기 위해 노트 식별자, 삭제 시각과 삭제 완료 상태를 담은 최소한의 로컬 삭제 기록은 남습니다. 이 기록에는 노트 제목이나 내용이 남지 않습니다.

제한과 보안 기대

이 버전은 번역, 실시간 전사·요약, 노이즈 제거·잘라내기 편집, 의미 기반 AI 검색, 필기 인식을 제공하지 않습니다. 로컬 단어 검색은 가능합니다. 기기 내 처리가 항상 오프라인으로 동작한다는 뜻은 아닙니다. 모델 준비·선택한 동기화·공유·백업은 네트워크를 이용할 수 있습니다. 회사 보안 인증이나 일반 iCloud의 종단간 암호화 보장을 주장하지 않습니다.
