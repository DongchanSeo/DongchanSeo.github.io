Haru Voice Notes의 정보 저장·처리와 사용자가 선택하는 전송 안내

안내 업데이트: 2026-10-05 · 버전 0.1.0 (9) · iOS·iPadOS·watchOS · 한국어·영어 화면

기기에 저장되는 정보

앱 저장소에는 녹음·가져온 음성, 전사문, 요약·제목 초안, 태그, 이전 글·그림·미리보기 이미지가 저장됩니다. 환경 설정에는 언어, 선택적으로 저장한 메일 받는 사람, 처리·동기화 상태, Watch 전송 대기열·수신 기록이 포함됩니다. 모델 준비 정보는 사용 가능 상태·확인 언어·마지막 확인 시각을 로컬 화면에 표시하며 진단 업로드 기능이 아닙니다. 앱 계정이나 개발자 사용자 프로필 서비스는 없습니다.

이전 요약에는 작성에 사용한 전사문 사본이 남습니다. 재전사는 현재 전사문을 교체하지만 이전 요약과 그 사본은 유지됩니다. 이전 글·그림·이미지는 읽기와 내보내기만 가능하며 새 작성·편집은 제공하지 않습니다. 이전 버전 파일이 남을 수 있습니다. 사진 보관함이나 카메라 권한을 요청하지 않으며 기존 그림 미리보기는 그림에서 생성한 이미지입니다.

사용자 요약 지시, 검토 상태와 관련 요약 정보도 노트와 함께 저장됩니다.

마이크와 기기 내 AI

마이크는 사용자가 시작한 녹음에 사용합니다. 전사는 지원되는 Apple 기기 내 음성 리소스를 이용하며 이전 음성 경로는 60초 이하로 제한됩니다. 요약·제목 초안은 사용 가능한 Apple FoundationModels 기기 내 모델을 이용합니다. 요약에는 호환 기기, 켜진 Apple Intelligence, 설치된 모델, 지원 로케일이 필요합니다. 음성 준비 상태와 요약 준비 상태는 별개입니다.

서버 음성 인식이나 외부 언어 모델로 대신 처리하지 않습니다. 첫 사용에 선택 언어의 음성 준비를 시도할 수 있으며 설정에서 상태 확인·새로고침·재시도가 가능합니다. 리소스 준비는 인터넷으로 Apple 리소스를 내려받을 수 있고 Apple Intelligence 준비는 시스템 설정을 따릅니다. 이 준비는 서버 AI 추론을 위해 노트 내용을 업로드하는 과정이 아닙니다. Apple 시스템 서비스의 자체 데이터 처리는 Apple의 설정과 정책을 따릅니다. 기기 내 추론이 항상 오프라인 동작이나 회사 보안 인증을 입증하지는 않습니다.

선택 사항인 iCloud·백업·Watch

새로 설치하면 iCloud Drive 동기화는 꺼져 있습니다. 켜면 저장·처리 완료·앱 활성화 후 저장된 음성, 전사문, 모든 이전 요약과 원본 전사문 사본, 이전 글·그림·관련 파일이 본인의 Apple 계정으로 자동 전송될 수 있습니다. 버전 정보에는 노트·버전 식별자, 시각, 파일 검증 값, 앱이 무작위로 만든 지속 기기 식별자가 포함됩니다. 저장 전 녹음과 Watch 전송 대기열은 노트 동기화에서 제외됩니다. 과거 버전과 충돌 파일은 남을 수 있고 동기화를 꺼도 기존 iCloud 사본은 남습니다.

iCloud 보안과 OS 관리 백업은 Apple 계정·시스템 설정을 따릅니다. 앱의 동기화 스위치는 기기 백업을 끄지 않습니다. 앱은 고급 데이터 보호를 켜거나 계정 보안 설정을 변경하지 않으며 일반 iCloud Drive의 종단간 암호화를 보장하지 않습니다.

완료된 Watch 녹음은 페어링된 iPhone으로 보낼 대기열에 들어갑니다. iPhone에서 로컬 전사·요약을 수행하고 짧은 결과를 돌려보낼 수 있습니다. 전송 후에도 Watch 원본·전송 상태·결과·수신 기록이 남을 수 있습니다.

메일·공유·지원 문의

내보내기는 사용자가 선택한 공유를 위한 로컬 파일을 만듭니다. 메일 초안에는 노트 제목과 최신 요약이 미리 입력되며 받는 사람·제목·본문을 편집할 수 있습니다. 전체 전사 TXT와 원본 M4A 첨부는 기본으로 꺼져 있고 선택해야 포함됩니다. 최종 전송은 시스템 Mail이나 선택한 공유 앱에서 직접 결정합니다. 선택 내용은 해당 서비스와 수신자에게 전달될 수 있습니다. 앱은 메일을 자동 전송하거나 메일 계정 인증 정보를 저장하지 않습니다.

앱의 메일 작성 흐름을 닫으면 임시 작성·첨부 파일의 삭제를 시도합니다. 흐름이 중단되거나 삭제에 실패하면 파일이 남을 수 있습니다. 이미 내보내거나 보내거나 공유한 사본은 해당 위치에서 독립적으로 보관됩니다.

2026년 10월 5일부터 지원 문의와 이메일은 문의 처리 목적을 달성하거나 더 이상 필요하지 않게 되면 지체 없이 삭제하는 기준을 적용합니다. 문의에는 민감하지 않은 예시와 필요한 오류 설명만 포함해 주세요. 원본 녹음·전사문·민감한 첨부, 계정 암호나 인증번호는 기본 문의 자료로 보내지 마세요. 불필요하게 받은 정보와 첨부, 운영자가 내려받아 보관한 불필요한 사본도 지체 없이 삭제합니다. 실제로 다른 법령에 따른 보존 의무가 있는 경우에만 해당 법적 근거와 보존 기간을 확인하고 다른 개인정보와 분리해 보관합니다.

보관·최근 삭제·영구 삭제

노트 삭제는 이 기기의 노트만 최근 삭제로 옮깁니다. 자동 만료는 없으며 복원하거나 명시적으로 영구 삭제할 때까지 남습니다. 복원하면 원래 식별자와 자산이 유지됩니다. 중단되거나 실패한 녹음은 복구를 위해 남을 수 있고 손상된 음성은 항상 복구되지 않습니다.

명시적인 영구 삭제는 해당 로컬 저장 자산, 관련 임시 초안·수신 기록, 검증된 앱 소유 노트별 내보내기 캐시를 제거합니다. 안전한 정리가 불가능하면 다시 시도할 수 있도록 복원 가능한 삭제 노트를 유지합니다. 일반 임시 내보내기 파일이나 중단된 메일 작성 사본은 그 밖의 경우 남을 수 있습니다.

로컬 삭제·동기화 해제·앱 삭제는 변경 불가능한 iCloud 과거 버전, Watch 원본, 다른 기기 노트, 이미 내보내거나 공유하거나 메일로 보낸 파일, 시스템 백업을 한꺼번에 제거하지 않습니다. 각 위치에서 따로 관리하세요. OS의 앱 삭제는 로컬 앱 데이터를 제거하지만 앱 정리하기는 데이터를 남길 수 있습니다. 백업 복원으로 보관된 데이터가 돌아올 수 있습니다.

영구 삭제 뒤에도 이전 iCloud·Watch 전송으로 노트가 다시 생기는 것을 막기 위해 노트 식별자, 삭제 시각과 삭제 완료 상태를 담은 최소한의 로컬 삭제 기록은 남습니다. 이 기록에는 노트 제목이나 내용이 남지 않습니다.

개발자 수집·추적·이 웹사이트

이 안내는 Haru Voice Notes 0.1.0 (9)의 iPhone·iPad 앱(iOS·iPadOS), 연결된 Apple Watch 앱(watchOS)과 이 웹사이트에 적용됩니다. 이 Apple 플랫폼 앱에는 Google Analytics·Firebase·광고 SDK나 개발자 수집 서버가 포함되어 있지 않습니다. 앱의 개인정보 매니페스트는 수집 데이터 항목 없음과 추적 꺼짐을 선언합니다. 모델 준비·선택한 iCloud·공유·OS 백업은 네트워크를 이용할 수 있습니다.

이 정적 페이지에는 타사 스크립트·웹 폰트·클라이언트 분석·문의 양식·업로드가 없으며, 페이지 자체에 쿠키 설정 코드가 없습니다. 이메일 링크는 사용자의 메일 앱을 엽니다. 이 웹사이트는 GitHub Pages에서 제공합니다. GitHub는 보안 목적으로 방문자의 IP 주소를 기록하고 보관합니다. GitHub의 처리와 보관은 해당 서비스 정책을 따릅니다. 자세한 내용은 GitHub Pages 데이터 수집 안내와 GitHub 개인정보 처리방침을 확인하세요.
