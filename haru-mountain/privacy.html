하루 명산 기록

개인정보 처리방침

시행일: 2026년 9월 20일 · 버전 1.0.0 · 빌드 3

1. 기기 내 산행 기록

하루 명산 기록은 계정 가입이나 개발자 서버 동기화 없이 사용할 수 있습니다. 산행 날짜, 방문 상태, 정상 도달 여부, 별점, 메모, 가고 싶은 산과 앱 설정은 사용자의 기기 내부에 저장하며 운영자에게 전송하지 않습니다. 앱을 삭제하면 앱 내부 기록이 삭제될 수 있습니다.

사용자가 백업 내보내기를 선택하면 기록이 JSON 파일로 만들어집니다. 파일은 사용자가 선택한 저장 위치나 공유 대상에 전달될 수 있으며, 그 서비스의 정책이 적용됩니다. 가져오기는 사용자가 선택한 파일을 읽는 동작입니다.

2. 위치와 지도

앱은 사용자의 현재 위치, 위치 권한 또는 GPS 이동 경로를 요청하지 않습니다. 앱에 포함된 명산 좌표를 Apple 지도에 표시할 때 지도 서비스 요청이 Apple에 전달될 수 있으며 Apple의 개인정보 처리방침이 적용됩니다. 산림청과 산림공간정보서비스 링크를 열면 해당 서비스의 정책이 적용됩니다.

3. 광고

산 상세 화면에 Google AdMob 네이티브 광고가 표시될 수 있습니다. 광고 요청에는 산행 기록, 날짜, 메모, 별점, 검색어를 넣지 않으며 비개인화 광고를 요청합니다. Google Mobile Ads는 광고 제공, 부정 사용 방지와 성능 측정을 위해 IP 주소, 기기 및 앱 정보, 광고 상호작용과 진단 정보를 처리할 수 있습니다. IP 주소를 바탕으로 대략적인 위치가 추정될 수 있습니다.

필요한 지역에서는 Google User Messaging Platform을 통해 광고 개인정보 동의 화면을 표시합니다. 제공되는 경우 앱 설정에서 광고 개인정보 옵션을 다시 열 수 있습니다. 자세한 내용은 Google 개인정보처리방침과 AdMob iOS 데이터 공개 안내를 참고해 주세요.

4. 삭제와 변경

산 상세 화면에서 개별 산행 기록을 수정하거나 삭제할 수 있습니다. 앱의 정보 처리 방식이 바뀌면 이 페이지와 시행일을 업데이트합니다.
