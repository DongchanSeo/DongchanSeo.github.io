1. 사진 접근과 사용 목적

Haru Photo Clean은 사용자가 직접 선택하거나 Android에서 접근을 허용한 사진을 검토하고, 보관·보호·삭제 후보를 정하거나 앱 안의 컬렉션으로 분류하는 데 사용합니다. Photo Picker로 선택한 사진만 사용할 수도 있고, 기기 사진 접근 권한을 선택할 수도 있습니다. Android 버전에 따라 전체 또는 일부 사진 접근이 제공될 수 있습니다.

앱은 사진의 URI 참조와 허용된 공개 메타데이터를 읽습니다. 여기에는 이름, 크기, 가로·세로 크기, 날짜, MIME 유형, 즐겨찾기 여부 등이 포함됩니다. 기기 사진의 상대 경로·폴더·파일명 단서는 스크린샷 후보 분류에 사용됩니다. 현재 앱 코드에는 사진 EXIF 위치를 요청하거나 원본 파일을 복사하는 경로가 없습니다. 선택 사진이 기기 또는 클라우드에 있는지는 앱이 단정하지 않습니다. Google Photos나 iCloud 전체 보관함을 자동으로 가져오거나 iCloud에 직접 연동하지 않습니다.

사진 접근을 거부하거나 변경하면 해당 범위를 기준으로 목록을 다시 확인합니다. 접근할 수 없는 사진은 작업 대기 목록에서 제외될 수 있으며, 기존 컬렉션과 검토 기록의 참조는 남을 수 있습니다. 참조가 남아 있다고 원본에 다시 접근할 수 있는 것은 아닙니다.

2. 미리보기와 이미지 분석

앱은 Android의 제공업체에 크기 지정 미리보기를 요청합니다. 현재 요청 크기는 720×720이며, 앱 코드가 원본 사진 파일을 다운로드하도록 요청하는 방식은 아닙니다. 그러나 제공업체는 내부에서 네트워크나 별도의 전송 방식을 사용할 수 있습니다. Haru는 제공업체의 내부 다운로드 크기·방식·계정 처리·진단 정보 처리를 제어하지 않습니다. 선택 사진을 제공하는 서비스의 정책과 설정도 확인해야 합니다.

미리보기는 앱 메모리에서 사용하며, 선택·제공업체 사진의 준비된 미리보기는 앱 전용 캐시에 저장합니다. 현재 메모리 캐시 한도는 20MiB, 디스크 미리보기 캐시 정리 기준은 64MiB입니다. 캐시는 시스템 저장 공간 관리, 앱 데이터 삭제, 앱 삭제 또는 접근 목록 갱신에 따라 없어질 수 있습니다. 기기 사진의 다음 몇 장만 미리 준비하며, 선택·제공업체 사진의 새 미리보기 준비는 사용자가 시작합니다. 준비는 오래 걸리거나 실패할 수 있으며 취소·재시도를 제공합니다.

유사 사진 분석은 사용자가 직접 시작하며 기기 안에서 미리보기의 시각적 특징을 비교합니다. 기본 분석은 기기 미리보기와 이미 준비된 선택 사진 캐시를 사용합니다. 선택·제공업체 미리보기도 새로 준비하려면 별도 선택이 필요합니다. 나란히 비교를 여는 것만으로 새 제공업체 미리보기 다운로드를 시작하지 않습니다. 유사 후보는 동일 사진이나 삭제 정답을 보장하지 않으며 자동 삭제하지 않습니다.

3. 기기에 저장하는 정리 기록

앱 전용 저장소에는 사진 URI와 메타데이터 참조, 사용자가 정한 컬렉션 이름과 소속, 방향별 컬렉션 선택, 모드별 검토 기록, 보관·보호·삭제 후보, 진행 중 세션과 되돌리기 정보, 선택한 사진 참조, 휴지통·복원 요청 상태, 검토 분량 및 다시 검토 설정이 저장됩니다. 사진 원본 위치나 다른 서비스의 앨범을 변경하는 컬렉션 동기화 기능은 없습니다.

앱은 정리 기록을 저장한 뒤 다음 판단으로 진행합니다. 저장된 기록은 다음 실행에서 이어갈 수 있지만, 사진 접근 권한을 다시 확인해야 합니다. 기록을 읽지 못하면 기존 파일을 보존하고 작업을 중단합니다. 사용자가 복구용 사본 보존 후 새로 시작하기를 선택하면 기기 내 복구 사본을 먼저 남깁니다.

동작 시각과 작업 종류를 기록하는 앱 전용 로그도 저장하며, 현재 로그 크기가 1MiB를 넘으면 기존 로그 내용을 지웁니다. 이 로그는 정리 상태의 기준 파일을 대신하지 않습니다. 앱 코드에는 이 기록을 앱 서버나 앱 계정으로 업로드·동기화하는 경로가 없습니다.

4. 선택적인 일일 알림

일일 사진 정리 알림은 기본으로 꺼져 있습니다. 사용자가 알림 설정 화면에서 직접 켜고 시간을 정할 수 있습니다. Android 13 이상에서는 필요한 알림 권한을 해당 화면에서 요청합니다. 권한 거부 또는 시스템·채널 차단이 확인되면 알림을 끄고 예약을 취소합니다. 사진 검토를 위해 알림을 켤 필요는 없습니다.

앱 전용 설정에는 알림 사용 여부, 선택한 시각, 다음 예약 시각과 마지막 알림 날짜가 저장됩니다. 알림은 기기에서 생성하는 일반적인 사진 정리 안내이며 사진 이름·이미지를 포함하지 않습니다. 기기 현지 시간을 따르고 Android 배터리 관리 등으로 늦게 도착할 수 있습니다. 정확한 시각을 보장하는 알람 권한이나 앱의 백그라운드 서비스를 사용하지 않습니다. 알림을 끄면 앱의 예약과 표시된 알림을 취소합니다. 재부팅·시간대 변경 등에서는 이미 선택한 설정을 다시 확인하며 기본 OFF 상태를 자동으로 켜지 않습니다.

5. 삭제 후보, 시스템 휴지통과 복원

삭제 후보를 정하는 동안 사진 원본은 즉시 바뀌지 않습니다. 앱의 마지막 검토 화면에서 사진 이름·수·제외 항목을 확인한 뒤 Android 시스템 확인에서 승인해야 휴지통 요청이 실행됩니다. 요청은 현재 접근 가능한 기기 사진 중 조건에 맞는 항목으로 제한됩니다. 보호·즐겨찾기 사진, 선택·제공업체 사진과 접근 불가 항목 등은 제외합니다. 앱은 영구 삭제를 요청하지 않습니다.

복원도 별도의 Android 시스템 확인을 거쳐 요청합니다. 시스템의 보관 기간 만료, 외부 삭제 또는 권한 변경 때문에 복원이 실패할 수 있습니다. 기기 갤러리·제공업체·백업 서비스의 동기화가 다른 기기나 클라우드에 미치는 영향은 해당 시스템과 서비스에 따라 달라지며 Haru가 제어하지 않습니다.

6. 광고, 외부 전송과 다른 서비스

앱은 광고나 광고 시청 조건을 제공하지 않으며, 사진이나 정리 기록을 개발자 서버로 업로드하거나 앱 계정으로 동기화하지 않습니다. Android와 사진 제공업체·제조사 서비스는 각 정책과 설정에 따라 정보를 처리할 수 있습니다.

앱 자체의 회원가입·계정 또는 사진 공유 전송 기능은 현재 구현되어 있지 않습니다. 따라서 앱 전용 계정 삭제나 서버 데이터 삭제 기능도 없습니다. 개인정보 관련 문의는 위 연락처로 보낼 수 있습니다.

7. 보관, 삭제와 백업 범위

앱 전용 기록과 설정은 기기에 보관되며, 앱 데이터 삭제나 앱 삭제 시 없어질 수 있습니다. 접근 권한을 해제하는 것만으로 기존 컬렉션·검토·복구 참조가 모두 지워지는 것은 아닙니다. 원본 사진을 지우거나 복원하려면 Android 시스템 또는 사진 제공 서비스를 이용해야 합니다.

현재 앱 설정은 앱 백업을 비활성화하고 백업·기기 전송의 root 영역 제외 규칙을 포함합니다. 기기 전송 동작은 제조사와 운영체제에 따라 달라질 수 있습니다. 이 설정은 갤러리·사진 제공업체·다른 백업 서비스의 원본 사진 동기화를 중단시키는 설정이 아닙니다.

문의 정보

운영자에게 문의를 보내면 발신 주소와 문의 내용은 답변·해결에 사용됩니다. 문의 정보는 필요한 동안 보관하고 불필요해지면 삭제하며, 법령상 보관 의무가 있으면 필요한 기간 보관합니다. 문의에 개인 사진이나 정리 기록을 첨부할 필요는 없습니다.
